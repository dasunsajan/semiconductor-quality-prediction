# Semiconductor Manufacturing Quality Prediction

Machine Learning Mini Project - Group 29

## Project Overview
Predict semiconductor manufacturing quality (Pass/Fail)
using the UCI SECOM dataset.

## Dataset
- 1,567 observations
- 590 numerical features
- Pass: -1
- Fail: +1

Dataset source:
https://archive.ics.uci.edu/dataset/179/secom

## Machine Learning Models
1. Logistic Regression
2. Support Vector Machine (SVM)
3. Random Forest

## Evaluation
- Precision
- Recall
- F1-score
- Balanced Accuracy
- Average Precision
- Nested Stratified Cross Validation

## Technologies
Python, pandas, NumPy, Matplotlib, scikit-learn
